Extract words and positions

src/indexing.py
Function: emit_positions()

Lowercases the text, splits on whitespace, and numbers every token from 1. Repeated words retain all their occurrences.

Show during the discussion: Each emitted record has the form ((term, document_id), position).

2. Calculations and saved data

Part C · Weighting, normalization, exports, and freshness checks

Calculate collection matrices

src/calculations.py
Function: calculate_collection()
VS Code · Ctrl+P: src/calculations.py:12

Derives Raw TF, Weighted TF, DF, IDF, TF-IDF, document lengths, and normalized weights from the index. Internal values are not rounded.

Show during the discussion: Compare the generated CSV values with the six TF-IDF analytics tabs.

Build the Query Vector

src/calculations.py
Function: query_vector()
VS Code · Ctrl+P: src/calculations.py:38

Counts query terms, applies existing Collection IDF, calculates the query length, and normalizes the weights. It does not calculate a new query IDF.

Show during the discussion: Query mathematics shows these steps and compares the query with a selected matching document.

3. Retrieval, ranking, and Flask

Part C · Source code for searching and document ranking

Match a complete phrase

src/queries.py
Function: phrase_matches()
VS Code · Ctrl+P: src/queries.py:14

Checks that words appear in the same document, in the correct order, at consecutive positions. Returns every starting position and token range.

Show during the discussion: In d5, machine learning starts at 1 and 9, spanning 1–2 and 9–10.

Boolean filtering and ranking

src/queries.py
Function: search()
VS Code · Ctrl+P: src/queries.py:45

Uses intersection for AND and set difference for AND NOT. Computes per-term cosine contributions and sorts the eligible documents by decreasing similarity.

Show during the discussion: For AND NOT, only the first phrase contributes to query weighting. The second phrase is an exclusion filter.

Connect the interface to the engine

app.py
Function: create_app()
VS Code · Ctrl+P: app.py:23

Creates Flask page, data, search, and download routes. Interactive requests use saved Spark results instead of starting a Spark job.

Show during the discussion: Use Search engine to run a query, then Query mathematics to inspect the calculation.
